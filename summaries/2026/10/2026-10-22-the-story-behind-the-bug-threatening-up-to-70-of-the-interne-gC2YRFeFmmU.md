# AI Discovers Critical Bug Affecting Up To 70% of World's Websites

- **Published:** 2026-10-22
- **Channel:** CBS News
- **Video:** [Watch on YouTube](https://www.youtube.com/watch?v=gC2YRFeFmmU)

## Summary
AI tools were used by hackers to discover a critical exploit in PHP technology, a foundational framework powering up to 70% of the world's websites, leading to urgent warnings and patches from cybersecurity agencies.

## Major Developments
### 1. AI-Discovered PHP Vulnerability
Hackers utilized AI tools this summer to find exploit code within PHP, a technology that has existed for over 20 years. The discovered bug allows remote code execution and could give attackers a direct path to server file systems or databases.

**Why it matters:** Because PHP is ubiquitous across the internet, powering government sites, WordPress sites, and an estimated 70% of the world's websites, a major exploit puts a vast portion of the global web infrastructure at risk of cyberattacks.

### 2. NSA Warning and Industry Response
In response to the vulnerability and subsequent leaks indicating exploit code was written before patches were released, the NSA issued an advisory telling organizations using PHP to immediately update their systems or take them offline until fully mitigated.

**Why it matters:** It demonstrates how AI can rapidly accelerate the discovery of complex vulnerabilities and highlights the intense race between tech maintainers and hackers when critical flaws are exposed.

## Key Takeaways
- AI tools can perform complex, long-term security analysis and find software vulnerabilities much faster than human researchers.
- PHP is a widespread foundational web technology, making any critical security flaw exceptionally dangerous.
- Cybersecurity agencies like the NSA stepped in with immediate remediation advice, advising system updates or taking vulnerable sites offline.
